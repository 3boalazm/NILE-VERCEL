## 0. المبدأ الأساسي (اربطه على الحيطة!)

كل عيب يمرّ بأربع حالات — وما يتقفلش بالقول "اتصلّح":

```
OPEN ──(المطوّر يعدّل + يربط الكوميت بـ F-xx)──> FIXED-CLAIMED ──(إعادة فحص آلي/يدوي)──> VERIFIED ──> CLOSED
```

- كل PR لازم يذكر أرقام العيوب (`Fixes F-12, F-34`).
- **"اتحلّ" = السكربت/الاختبار بيقول FIXED بالإثبات** — مش رسالة من أحد.
- الأداة نفسها اتثبت عليها ده: أول ما اشتغلت كشفت **غلطتين في تقاريري** (CI/Dockerfile/vitest كانت موجودة ومفوّتة — انظر Corrections Log في السجل). التحقق المتكرر بيلقط حتى المُختبِر.

**طريقة التشغيل بعد كل دفعة إصلاح:**

```bash
cd /home/user/NPF

```

> **تشغيل المتصفح في بيئة مفيهاش `npx playwright install`:** التنزيل من
> `storage.googleapis.com` مقفول، لكن `@sparticuz/chromium` بايتاته موجودة محلياً
> في `node_modules/@sparticuz/chromium/bin/chromium.br`. الثنائي محتاج مكتبات
> NSS/NSPR من `bin/al2023.tar.br` — سكربت الـprobe بيفكّها لوحده لـ`/tmp/al2023`
> وبيمررها عبر `LD_LIBRARY_PATH` (الحزمة نفسها بتفكّها تلقائياً على Amazon Linux
> 2023 فقط). من غير المكتبات دي الخطأ بيطلع
> `libnspr4.so: cannot open shared object file`.

## 4. بروتوكول إعادة التوقيع النهائي (Closing the register)

1. `verify-fixes.mjs` يطبع **AUTO: N FIXED / 0 OPEN**.
2. كل بنود `MANUAL CHECKS` (25 بنداً) موثّقة نتائجها (سكرين شوت/تقرير Lighthouse/خروج axe).
3. أعد حزمات التوقيع الأصلية (المذكورة في كل `results/XX`): link sweep + console sweep + load battery + auth/forms/offline probes + Lighthouse.
4. حدّث `results/24-test-defect-register.md`: حوّل كل F إلى CLOSED مع تاريخ + رقم الكوميت.
5. **جولة تقرير 21 (Regression)** هي الفرصة الأخيرة: لو 64/64 خضراء → البرنامج اتقفل.

```yaml
# اقتراح إضافة لـ .github/workflows/ci.yml (job جديد):
  verify-fixes:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      # ... setup + build + start ...
```

الـexit code = عدد العيوب المفتوحة الآليّة → أي ريجريشن في F-01..F-71 المُغلقة يكسّر الـCI فوراً.
