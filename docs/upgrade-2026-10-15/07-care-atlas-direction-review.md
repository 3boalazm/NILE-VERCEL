## لماذا توقّفنا عن تعديل التصميم السابق؟

المستخدم رفض Prismatic Care بعد رفض Clinical Glass، وطلب صراحةً ألا نعتمد على الموجود وأن نقلب الموقع حرفيًا. التحليل والخطة الجديدة محفوظان في [06-zero-base-reset.md](06-zero-base-reset.md).

لم نعتبر الاختبارات السابقة قبولًا ولم ننقل نتائجها لهذه النسخة. قبل استثمار موجة كاملة أخرى في تعميم اتجاه غير متفق عليه، بُني نموذج حقيقي مستقل، يغيّر الفكرة وطريقة العرض والتفاعل. هذا تسليم مرحلة اتجاه بصري، وليس ادّعاء بإنجاز كل الطلب النهائي.

## ما الذي تغيّر من الأساس؟

### ١. الإنسان قبل العلبة

مشهد كامل بصورة إنسانية تحريرية، عنوان «الحياة أولًا»، وشبكة هندسية. لا عبوة عملاقة في hero، لا artwork زجاجي بنفسجي، لا ناف عائم داخل capsule، ولا استعارة ثنائية sans/serif من Ummah. المكمّلات والأجهزة واضحة في الرسالة الأولى حتى لا تبدو الصفحة علامة سياحية أو وعدًا صحيًا عامًا.

الصورة الرئيسية **مولّدة توضيحيًا** وموسومة بذلك في footer؛ ليست صورة عميل أو نتيجة علاج. لم تُصنع شهادة أو قصة نجاح حول الشخصين فيها. glass مقتصر على مذكرة فوق الصورة ورابط مستند وظيفي، لا وصفة لكل سطح.

### ٢. أطلس، لا رف كروت

فهرس واحد يضع قائمة المنتجات بجوار ملف المنتج المفتوح. الاختيار يغيّر العبوة، الوصف، الشكل الدوائي، التركيب/مواصفات الجهاز، الاستخدام، والنشرة دون الخروج إلى صفحة أخرى. على الموبايل تتحوّل القائمة إلى شريط اختيارات أفقي داخل حدوده، ثم ملف المنتج.

- 8 منتجات من بيانات المستودع العامة، بلا أسعار تجريبية أو مخزون مختلق.
- بحث بالاسم العربي/الإنجليزي، تصفية مكملات/أجهزة، وعدّاد حقيقي للنتائج وحالة خلو واضحة.
- اختيار بلوحة المفاتيح بأسهم الاتجاهات وHome/End مع الحفاظ على التركيز.
- مكوّنات وسياق جرعة من البيانات نفسها؛ لا تغيير للقيم.
- PDF فقط عند وجود نشرة أصلية في الملفات. عند عدم توفرها تظهر رسالة صريحة، لا ملف تسويقي بديل.
- التبديل اللغوي يحفظ المنتج المختار وحالة تبويب التفاصيل.

أُعدت ست عبوات مقصوصة من صورها الأصلية لإزالة المشاهد التسويقية السابقة. لا توليد أو إعادة كتابة للعبوات، وشكل الجهاز يظل صورته الأصلية. مصادرها ومناطق القص موثقة في `packs/SOURCES.md` و`scripts/prepare-care-atlas-packs.py`.

### ٣. المعرفة أداة، لا صف ادعاءات

فصل أزرق واضح «اقرأ قبل أن تختار»: أسئلة قابلة للفتح عن الكميات وسياق الجرعة، الفرق بين دراسة مكوّن ودراسة منتج، والرجوع للمختص. لا ادعاء فاعلية جديد ولا ضمان نتيجة. رابط النشرة يسمّي المنتج الذي يخصه؛ عند اختيار منتج دون PDF لا يُختلق ملف له.

### ٤. نظام بصري مستقل

- Ink navy / electric blue / warm paper / acid accent، بدل lavender/plum.
- IBM Plex Sans Arabic وأوزان حقيقية؛ Arial للإنجليزية، بلا Banzeen أو Glora أو Montserrat/Georgia في هذا النموذج.
- شبكة تحريرية، عناوين كبيرة وأرقام فهرس، وكتل متباينة بدل تكرار مقاسات الكروت.
- تواصل مباشر ببريد/هاتف موجودين فعلًا. لا نموذج يزعم حفظ رسالة، ولا شراء وهمي.

## استقلال الكود ونطاق الدمج

النموذج في `public/concepts/care-atlas/` وله HTML/CSS/JavaScript مستقلة تمامًا. لا يستورد homepage components أو `globals.css` أو أي مكوّن واجهة قديم. ليس CSS override جديدًا فوق النسخة المرفوضة.

استخدم فقط الهوية الاسمية والشعارات الموجودة، بيانات المنتجات العامة والنشرات، وصور العبوات الأصلية. إصلاحات التجارة والأمان والاستعادة من الموجة السابقة لم تُلغَ ولم تُعد كتابتها.

**لم يُعمّم هذا الاتجاه على الرئيسية الفعلية أو الكتالوج/الحساب/الدفع/لوحات الإدارة.** ملفات public تدخل بناء Next المعتاد لاحقًا؛ المعاينة الحالية تخدمها بخادم static مستقل فقط. الخطوة التالية بعد مراجعة الاتجاه: إعادة بناء shell والمحتوى والمسارات الأساسية بنفس النظام، ثم دمج حقيقي واختبارات المتجر الكاملة. لا نفترض الموافقة على هذا الاتجاه.

## إعادة التشغيل

```bash
node scripts/serve-care-atlas.mjs
# http://localhost:3100/ redirects to the standalone concept
```

يستمع الخادم على `0.0.0.0`، يقبل GET/HEAD فقط، ويخدم أنواع ملفات عامة محددة داخل public، بلا DB أو معاملات. يرسل CSP ذاتي المصدر وnosniff، ولا يمنع iframe الخاص بمعاينة Arena.

إعادة تصدير البيانات العامة دون الأسعار أو شهادات العملاء:

```bash
node scripts/export-care-atlas-catalog.mjs
# Optional pack regeneration; requires Pillow as local tooling:
python scripts/prepare-care-atlas-packs.py
node scripts/export-care-atlas-catalog.mjs
```

الفحص واللقطات، بعد تثبيت axe-core منفصلًا كأداة تدقيق:

```bash
npm install --prefix .cache/browser-tools --no-save --no-package-lock axe-core@4.14.0
AXE_CORE_PATH=.cache/browser-tools/node_modules/axe-core/axe.min.js node scripts/validate-care-atlas.mjs
```

في sandbox الحالية: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/tmp/chromium LD_LIBRARY_PATH=/tmp/lib`. خارجها يستخدم Playwright متصفحه الافتراضي. المسارات المؤقتة ليست جزءًا من المشروع. المصدر الافتراضي للفحص هو المنفذ 3100؛ يمكن تغييره بـ`CARE_ATLAS_URL`.

## الحدود والقرارات المفتوحة

- قبول المستخدم للفكرة أولًا، لا قبول تلقائي من الوكيل.
- تعميم حقيقي للاتجاه على باقي الموقع لم يتم بعد.
- النص الطبي من المستودع لا يعني اعتماد مراجعة طبية جديدًا؛ يلزم اعتماد المالك/المختص، خصوصًا الأوصاف وتعليمات الاستخدام.
- بوابات التجارة والبريد والحاوية والإطلاق، ومخاطر الاعتماديات المسجلة في [02-security-and-release-gates.md](02-security-and-release-gates.md) ما تزال مفتوحة. لم يُعَد npm audit في هذه المرحلة.
- لا commit أو push أو deployment. Google Doc التاريخي لم يُحدّث؛ ملفات 06 و07 هي سجل المرحلة الحالي.
