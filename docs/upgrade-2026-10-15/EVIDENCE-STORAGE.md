# Evidence included in this pull request

The pull request includes the implementation, original site assets, Markdown
plans/reports, machine-readable browser results, test logs, and the four compact
screenshots from the final discovery/reading round in `discovery-evidence/`.

Historical PNG/WebP review captures (approximately 100 MiB) remain in the Arena
workspace and are intentionally ignored by Git. Older reports retain their
workspace-relative image links as historical references; those image links are
not expected to resolve from a fresh Git clone. Their written findings and JSON
results are included. Site imagery under `public/` is **not** excluded.

To regenerate current full-site screenshots, run
`scripts/validate-integrated-care-atlas.mjs` with the application running and
`PLAYWRIGHT_BASE_URL`, `CARE_ATLAS_EVIDENCE_DIR`, and `AXE_CORE_PATH` configured.
Set `CARE_ATLAS_SCREENSHOTS=0` when only the JSON validation is needed.
The focused final-round evidence is generated by
`scripts/validate-discovery-polish.mjs`.
