# صور تحريرية متنوعة والهيدر بالعلامة وحدها

> تقرير الجولة السابقة محفوظ بنتائجه وروابط معاينته وقت التسليم. [أحدث جولة وتقرير التحقق وروابط المعاينة الحالية](13-discovery-and-reading-polish.md).

## التكليف — 2026-10-15
المستخدم طلب صورًا متناسقة مع الصورة الرئيسية في أماكن مختلفة، مع تنويع خارج المشاهد البشرية. أي سيدة تظهر بحجاب كامل وملابس محتشمة، وتجنب ملامح الوجوه عامة. الهيدر يحمل العلامة البصرية فقط دون اسم مكتوب أو tagline؛ الاسم المنطوق يبقى للإتاحة.

## خطة التوزيع
1. about: مشهد إنساني من الخلف، زوجان يمشيان في حديقة معاصرة، حجاب كامل وملابس واسعة، بلا وجوه واضحة. لا تقديم الصورة كفريق أو عميل أو مؤتمر.
2. story: مشهد عمارة وممر حجر وزجاج هادئ، بلا أشخاص؛ توضيحي لا يمثل مقر الشركة.
3. quality-sourcing: تصوير تحريري للخامات والورق والزجاج والضوء، بلا أشخاص أو منتجات/نتائج/شهادات مخترعة؛ ليس توثيق معمل أو مكونات فعلية.
4. contact: still life للورق والضوء والأدوات البسيطة، بلا أشخاص أو بيانات متخيلة؛ لا يزاحم النموذج.

## التنفيذ والتحقق المخطط
- أربع صور مستقلة، ملفات JPEG مضغوطة ومقاسات محسوبة، تحميل lazy أسفل المقدمة، وعدم تغيير صور العبوات الحقيقية.
- مراجعة كل صورة قبل الدمج، وتسمية توضيحية صريحة لكل موضع، وعدم إظهار صورة معارض قديمة ذات وجوه واضحة في الموضع الذي يستبدل.
- استخراج مسارات العلامة البصرية من SVG الأصلي، بلا توليد شعار بديل أو إخفاء الاسم بقص CSS فقط. aria-label لرابط الرئيسية، والاسم لا يعود داخل القائمة المحمولة.
- مراجعة عربية/إنجليزية وموبايل/ديسكتوب، وتحقق تحميل الصور والـoverflow والإتاحة والتنقل والنماذج. لا تعديل لمنطق الشراء أو الحسابات.

راجعت الصور الأربع الأصلية قبل الدمج، ثم لقطاتها داخل الصفحات. المشاهد متسقة مع الساحل والخامات الطبيعية والورق والكوبالت دون أن تتشابه في المحتوى كله. الصورة الرئيسية ذات الحجاب الكامل بقيت كما هي، وصور العبوات الحقيقية لم تتغير.

أُزيل عرض صور المعارض ذات الوجوه الواضحة من المواضع الحالية في about/story/careers. بقيت الملفات الأصلية والأدلة التاريخية محفوظة دون حذف، وبقي نص الحضور بالمؤتمرات مستندًا إلى المحتوى الأصلي، منفصلًا عن الصور التوضيحية.

### التهيئة والصدق البصري

- الصور الأربع 1264×848، JPEG محسّن، إجمالي **642,413 بايت** للملفات الأصلية الأربعة، وكل ملف دون 300KB. Next Image يقدم المقاسات المناسبة والتحميل الكسول تحت المقدمة، مع أبعاد ثابتة لتقليل تغير التخطيط.
- كل موضع له alt عربي/إنجليزي وتعليق صريح بأنه مشهد مولّد توضيحي لا يمثل الفريق أو المقر أو المعمل. لا توثيق منشأة مزيف ولا رسم توليدي يحل محل عبوة منتج.
- المصدر والتحضير والحدود في `public/care-atlas/editorial/SOURCES.md`، والتنفيذ عبر `EditorialVisual` وCSS مخصص له.
- الحجاب الكامل وتجنب الوجوه راجعتهما بصريًا، لا ادعاء بأن اختبارات برمجية أثبتت ذلك.

### الهيدر

- `npf-mark-white.svg` مستخرج من **مسار الرمز الأصلي نفسه**؛ ليس إعادة توليد للشعار، ولا إخفاء للنص بقص CSS. لا wordmark مصغر أو TM أو tagline داخل الملف الجديد.
- لا اسم مكتوب أو tagline بجوار العلامة في رأس الرئيسية أو الداخلية أو الـglass dock.
- قائمة الموبايل تحمل العلامة كذلك؛ اسم الجهة بقي فقط في النص المخفي لقارئ الشاشة/aria-label، للحفاظ على اسم الرابط وعنوان الحوار.
- كُبّرت مساحة اللمس وحُفظت الأبعاد، وتمركز التنقل على الديسكتوب، والانتقال إلى قائمة الموبايل عند العرض الوسيط قبل تزاحم الأدوات.
- اسم الشركة في محتوى الصفحات والفوتر لم يُحذف؛ الطلب خاص بالهيدر.
- أضيف ملف العلامة فقط إلى allowlist الميديا العامة للـPWA؛ لا توسيع لتخزين API أو الصفحات الخاصة.

## الحدود

هذه صور تحريرية معلنة لا إثبات حقائق تجارية أو طبية. الخدمات الحية وشراء فعلي وبريد وتدفقات عميل مسجّل لم تعتمد بهذه الجولة؛ المعاينة وقيودها لا تزال قائمة. لا تدقيق npm جديد ولا إغلاق لبوابات الأمن السابقة. لم تتغير إجراءات الحساب أو المال أو سياق الاستفسار المتحقق.

لا commit أو push أو deploy أو مزامنة خارجية جديدة. كل العمل على `arena/2f247beb-npf`، والتقرير والأدلة محفوظان محليًا Markdown. نتائج المراحل السابقة تبقى بتاريخها وحدودها؛ الأرقام أعلاه من الجولة الجديدة نفسها.
