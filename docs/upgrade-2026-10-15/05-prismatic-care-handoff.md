## ٢. الفرق التنفيذي

### المشهد الأول

- عنوان إنجليزي كبير بتباين Montserrat/Georgia، وعنوان عربي بخط الموقع العربي. مساحات مفتوحة بدل hero داخل كارت تقليدي.
- مشهد تجريدي زجاجي صُمم لهذه النسخة، وطبقة مستقلة لعبوة Proxeed Plus الأصلية المستخرجة من الصورة الموجودة. لم تُولَّد عبوة أو كتابة طبية بديلة.
- بطاقتا زجاج وظيفيتان: صفحة الجودة والمصدر، ونشرة PDF فعلية. الأولوية البصرية تخدم الوصول إلى المعلومات لا زينة بلا وظيفة.
- الفن الزجاجي مولّد اصطناعيًا للعرض فقط؛ ليس صورة مصنع أو مختبر أو إثبات تصنيع/فعالية.

### اختيار مفيد، ثم قصة منتج

- الاختيار بين صحة الرجل / صحة المرأة / الأجهزة يغيّر المنتجات المعروضة وعدد المجموعة. الرابط يفتح فلتر الكتالوج الصحيح فعلًا.
- أزرار قياسية تدعم لوحة المفاتيح و`aria-pressed` و`aria-controls`، مع إعلان المنطقة المتغيرة. روابط بديلة داخل `noscript` عند غياب JavaScript.
- عرض تحريري لمنتج Proxeed Women: الصورة، الوصف، أول ثلاثة مكوّنات مع ملاحظة سياق الجرعة من بيانات المنتج، ورابط التفاصيل والاستفسار.
- فصل داكن للمصدر والتوزيع، ثم المعلومات العلمية والنشرات، ثم ختام طباعي كبير للتواصل. ترتيب واضح بدل تكرار صف الكروت نفسه.
- لا تشخيص طبي، لا توصية علاجية آلية، ولا أرقام نجاح أو آراء عملاء مصطنعة. العدّادات من بيانات الكتالوج.

### التكيّف والاعتمادية

- اتجاه RTL حقيقي، تكوين موبايل مستقل وcollection أفقي داخل المنطقة لا خارج الصفحة، ووضع داكن كامل.
- حركة خفيفة قابلة للإلغاء مع reduced motion، ومحتوى SSR لا ينتظر التحريك ليصبح ظاهرًا.
- إصلاحات الأمان والاستعادة والأسعار والمفضلة وخصوصية PWA من الموجة السابقة محفوظة. أُضيف مسار الفن إلى قائمة الصور الثابتة الآمنة للكاش، دون فتح كاش الصفحات الخاصة.

### ما كشفت عنه المراجعة وأُصلح

- قياس أولي أظهر تباينًا منخفضًا أثناء لحظة انتقال ثيم روابط المعلومات العلمية؛ أُوقفت انتقالات اللون/الخلفية المتعارضة على هذه الروابط، ويُنتظر استقرار الثيم في أداة القياس.
- أضيفت ملاحظة سياق المكونات حتى لا يُعرض جدول الجرعات دون سياق بياناته الأصلي.
- اختبار التواصل القديم كان يطلب نجاح الحفظ رغم حظر الحفظ في preview؛ عُدّل إلى فرعين صريحين دون تغيير عقد الإنتاج. حُصر alert داخل main بدل مصادفة live region الخاص بإعلان المسار.
- أداة الالتقاط لا تنتظر `decode()` لصور مجموعات مخفية بـ`hidden`؛ يتم تمرير الصفحة وتحميل الصور المعروضة فقط. أضيف حد انتظار حتى لا يعلق الفحص بسبب lazy images مخفية. هذا تعديل لأداة التحقق، لا إخفاء فشل في الموقع.
- فُحصت بصريًا لقطات العربية/الإنجليزية على desktop والموبايل، ثم اللقطة العربية الكاملة والوضع الداكن الإنجليزي. لا ادّعاء بفحص بصري يدوي لكل عرض وكل حالة.

## ٤. إعادة التشغيل

بعد تثبيت المشروع وتشغيل بناء preview على المنفذ 3000:

```bash
NPF_PREVIEW_MODE=1 PLAYWRIGHT_BASE_URL=http://127.0.0.1:3000 npm run test:e2e
npm test
npm run lint
npx next typegen && npx tsc --noEmit
```

أداة responsive/axe واللقطات محفوظة في `scripts/validate-design-preview.mjs`. لا تُضاف اعتماديات التدقيق إلى حزمة الإنتاج:

```bash
npm install --prefix .cache/browser-tools --no-save --no-package-lock axe-core@4.14.0
AXE_CORE_PATH=.cache/browser-tools/node_modules/axe-core/axe.min.js node scripts/validate-design-preview.mjs
```

في sandbox هذه الجلسة استُخدم Chromium 153 من `@sparticuz/chromium@153.0.0`، مع `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/tmp/chromium` و`LD_LIBRARY_PATH=/tmp/lib`. خارج sandbox يكفي متصفح Playwright المثبت افتراضيًا؛ المسارات `/tmp` ليست جزءًا من المستودع. إعداد المسار الاختياري لا يغيّر متصفح CI الافتراضي.

## ٥. ما لا يزال مفتوحًا

1. **القبول البصري للمستخدم.** النسخة الأولى مرفوضة، والثانية تحت المراجعة؛ بند التصميم لا يُغلق بقرار من الوكيل.
2. مراجعة مالك المحتوى/مختص طبي للادعاءات والمصادر والصياغات، بما فيها وصف المنتج وعبارة التصنيع الأوروبي من المحتوى القائم.
3. بوابات [الأمان والإطلاق](02-security-and-release-gates.md): آخر تدقيق اعتماديات محفوظ ما زال **25 ثغرة، منها 16 high**؛ لم يُعَد تدقيق npm في هذه الموجة ولم تتغير شجرة الاعتماديات خلالها. لا يُمثَّل الوضع آمنًا بالكامل.
4. قبول PostgreSQL/Payload/Vendure، الطلب والدفع والمخزون، البريد الحقيقي وSMTP، الحاوية، واختبارات الأجهزة/قارئ الشاشة. المعاينة لا تحقق هذه البوابات.
5. Report-only CSP، حدود rate limiter داخل الذاكرة ومراقبة/توزيع الإنتاج تبقى حسب التقرير الأمني. لا أرقام Core Web Vitals أو تحسين تحويل مقاسة في هذه الموجة.
6. تغييرات محفوظة في فرع الجلسة فقط؛ لا commit/push/merge/deployment في هذه الموجة. لم يُحدَّث Google Doc القديم هنا؛ هذا التقرير هو مرجع V2 الحالي.
