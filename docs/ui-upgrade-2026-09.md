## 1) السبب الجذري الذي كان يخفي المحتوى (P0)

القياس على HTML الخادم للصفحة الرئيسية `/ar` قبل التعديل: **23 عنصرًا** يصل إلى
المتصفح بـ `style="opacity:0"` — من ضمنها غلاف الـ `template.tsx` الذي يلفّ
**الصفحة كلها**. أي تأخير/فشل في الـ hydration أو في `IntersectionObserver` =
صفحة بيضاء بالكامل، وبدون JavaScript الموقع لا يظهر أصلًا.

**العقد الجديد** (`src/components/npf/motion/reveal.tsx` + `globals.css`):

| الحالة | قبل | بعد |
| --- | --- | --- |
| HTML الخادم | مخفي (`opacity:0`) | **ظاهر بالكامل** — لا يوجد أي `opacity:0` في الـ HTML |
| JS معطّل | صفحة بيضاء | كل شيء ظاهر (لا يوجد `html.js` → لا إخفاء) |
| الـ hydration بطيء/فاشل | مخفي حتى يكتمل | ظاهر؛ لا يُخفى أي عنصر إلا بعد أن يثبّته React (`data-reveal-armed`) **وهو أسفل الشاشة** |
| الـ Observer لا يُطلق | يبقى مخفيًا للأبد | مسح احتياطي على scroll/resize يكشف كل ما مرّ به المستخدم (القفز بـ End أو الـ anchors) |
| `prefers-reduced-motion` | حركة مع إخفاء | **لا حركة ولا إخفاء** |
| الطباعة / PDF | فارغ | كل شيء ظاهر (`@media print`) |

الـ hero له دخول CSS-only (`.hero-enter*`) يبدأ من أول paint ولا ينتظر
الـ hydration، وانتقال الصفحة (`.page-enter`) أصبح CSS keyframes ولا يعمل في
cart/checkout/account/login/register.

**ملاحظة قياس مهمة:** Chrome لا يحتسب أي عنصر رُسم أول مرة بـ `opacity: 0`
كمرشّح لـ LCP — لذلك كان الـ LCP في النسخة القديمة يقع على رابط في القائمة
بحجم 1,890px² بدل صورة الـ hero. الحركات الجديدة تبدأ من opacity مرئي (0.35–0.5)
للعناصر الكبيرة، ومن 0 فقط للزخارف الصغيرة (eyebrow/chips).

## 2) ما تم تنفيذه

### P0 — أمان ووضوح
- `Reveal` مُعاد كتابته بدون framer-motion (attributes على الـ DOM + CSS transitions، observer واحد مشترك، مسح احتياطي passive على scroll).
- `CounterStats` يُرسل القيمة الحقيقية من الخادم (كان يُرسل `0`)، والعدّ التصاعدي للأرقام الصغيرة فقط (لا يعدّ "2019" أو "2030").
- أهداف اللمس ≥ 44×44 على الموبايل: زر المفضلة، زر السلة، أسهم ونقاط الكاروسيلات، مبدّل اللغة، شعار الهيدر، روابط الـ breadcrumb، pills الفلاتر.
- الهيدر على 375px لم يعد يفيض أفقيًا (حساب/مفضلة انتقلا إلى ورقة "المزيد" في الشريط السفلي على الشاشات < 640px).
- الشريط السفلي: حالة نشطة **غير لونية** (شريط علوي + وزن خط + `aria-current`)، و`main` يحجز `4rem + safe-area-inset-bottom` حتى لا يغطي الشريط أي زر إرسال.
- صور الـ hero التزيينية `alt=""`، وصورة المنتج لها وصف حقيقي (`heroImageAlt`).
- إصلاح تحذير hydration قديم في زر القائمة (`data-slot` mismatch) وإصلاح CLS من شعار Alfasigma (نسبة أبعاد خاطئة).

### P1 — ترقية ملموسة (بالترتيب المتفق عليه)
1. **Hero تحريري**: eyebrow، عنوان كبير، lead، CTA أساسي (Magnetic على زر واحد فقط) + "لماذا تثق بنا؟" → `#trust`، 3 شرائح ثقة، صورة منتج مع بطاقة دليل سريري وشريحة الشريك.
2. **شريط الإثبات** بأرقام حقيقية فقط: 2019 (التأسيس) · 8 (منتجات الكتالوج) · 2 (فئات رئيسية) · 2030 (سريان تسجيل NFSA) + marquee الشركاء الموثّقين.
3. **Product Spotlight** (`product-spotlight.tsx`): منتج واحد بحجم كبير، "لمن يناسب؟"، الشكل المتاح، التوفر، السعر، "أهم ما يميزه"، CTA "تصفّح المنتج" + "اطلب معلومات"، أسهم RTL-aware وصور مصغّرة.
4. **Trust Journey** (`trust-journey.tsx`): 4 خطوات مرقّمة على مسار يمتلئ مع التمرير (`--journey-progress`، transform فقط؛ مرسوم بالكامل بدون JS/مع reduced motion).
5. **Shop by Need** (`shop-by-need.tsx` + `lib/products/positioning.ts`): صحة الرجل / صحة المرأة / أجهزة طبية / العناية بالأسنان (قريبًا، غير قابلة للنقر)، كل بطاقة تربط بـ `/products?need=…`.
6. **بطاقة المنتج** الجديدة: تصنيف/جمهور، اسم، فائدة، شكل، توفر + سعر، CTA، hover متوازن، لا نص فوق الصورة.
7. **قسم الدليل** (`evidence-block.tsx`): يشرح "مبني على أدلة" ويعرض عدد المراجع المنشورة **المحسوب من الكتالوج** (مع إزالة التكرار) + نشرات PDF الرسمية.
8. صفحة المنتجات: فلاتر حسب الاحتياج (3) + الفئات، والـ PDP: معرض الصور sticky على الديسكتوب.
9. صفحة "من نحن": باند مبادئ — *وضوح قبل التسويق / دليل قبل الادعاء / ثقة قبل البيع*.

### P2 — حركة محسوبة
- كل الحركات opacity/transform/clip-path فقط، مع fallback مرئي.
- parallax خفيف لصورة الباند التحريري فقط عبر CSS scroll-driven animation (`animation-timeline: view()`) — بدون JS، ويختفي تلقائيًا مع reduced motion أو المتصفحات غير الداعمة.
- انتقال صفحة خفيف (0.3s) مستثنى من cart/checkout/account.
- لا WebGL، لا cursor effects، لا infinite scroll، لا magnetic على كل الأزرار.

## 5) قرارات وحدود واعية

- **لا ادعاءات جديدة**: كل الأرقام محسوبة من الكتالوج أو من حقائق موثّقة في القاموس (التأسيس 2019، توزيع Alfasigma الرسمي، تسجيل NFSA حتى 2030، شركاء التصنيع). لم نستخدم أي نسب نجاح/تحويل.
- الـ IntersectionObserver **غير الموجود** أصلًا (متصفحات قبل 2019) خارج النطاق: `embla-carousel` نفسه يحتاجه؛ `Reveal` محمي ضده على أي حال.
- الـ hero الداكن والـ WebGL ما زالا خلف أعلام البيئة (مطفأين افتراضيًا) ولم يُلمسا.
- الـ `.env` والـ `.cache/` المحليان (أدوات القياس واللقطات) غير مضمّنين في الـ Git.
